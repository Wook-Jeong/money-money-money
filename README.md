# Money! Money! Money — v1.1

가볍게 동작하도록 Vanilla HTML/CSS/JavaScript만 사용한 PWA 프로토타입입니다.
프레임워크나 빌드 과정이 없습니다.

## 실행

파일을 더블클릭하지 말고 간단한 로컬 웹서버로 실행하세요.

```bash
cd Money_Money_Money_v1
python3 -m http.server 8000
```

Mac 브라우저에서 아래 주소를 엽니다.

```text
http://localhost:8000
```

## 현재 구현 기능

- Hot: 최근 50회 Hot 번호 4개 + Hot 후보군을 제외한 번호 2개
- Hot + Cold: 최근 50회 Hot 3개 + Cold 3개
- Recent 100: 최근 100회 출현 횟수 기반 가중 추출
- Balanced: 홀짝 3:3, 저/고 3:3, 합계 100~180, 번호대 최대 3개, 3연속 이상 제외
- Random: 1~45 균등 무작위
- 게임 간 완전 동일 조합 방지
- 게임별 새로고침
- '어떻게 생성됐나요?' 기본 닫힘
- 마지막 생성 결과 자동 저장
- 상단 `↺ 초기화` 버튼: 체크 선택/생성 결과/마지막 저장 결과를 지우고 처음 상태로 복귀 (로또 데이터 캐시는 유지)
- 최근 로또 데이터 로컬 캐시
- PWA 기본 구성

## 데이터

현재 프로토타입은 공개 JSON 미러를 순차적으로 사용합니다.

1. smok95.github.io/lotto
2. papaya5rhw1984.github.io/lotto-data

앱에서 필요한 최근 120회만 로컬에 저장합니다.
첫 실행 때는 인터넷 연결이 필요하며, 한 번 데이터를 받은 뒤에는 저장된 데이터로 다시 열 수 있습니다.

장기적으로는 외부 미러 의존성을 없애기 위해 이 프로젝트 전용 JSON 데이터 파일을 GitHub Actions가 매주 갱신하도록 바꾸는 것을 권장합니다.

## 참고

과거 출현 빈도는 다음 회차의 당첨 가능성을 높이지 않습니다. 이 앱의 Hot/Cold/Recent 기능은 통계 기반 번호 생성 방식일 뿐 당첨 예측 기능이 아닙니다.
